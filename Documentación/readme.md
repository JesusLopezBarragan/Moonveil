📚 Documentación del videojuego

Esta carpeta contiene la documentación relacionada con el desarrollo del videojuego, estructurada en carpetas para que no haya perdida.

Aquí se recoge información sobre el diseño, la historia, los personajes, las mecánicas de juego y los aspectos técnicos del proyecto.

La documentación se actualizará a medida que avance el proyecto, reflejando los cambios y las nuevas funcionalidades implementadas.
